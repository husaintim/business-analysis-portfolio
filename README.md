# Портфолио бизнес-аналитика: моделирование процессов и проектирование ИС

Материалы выпускной работы бакалавра (РТУ МИРЭА, «Бизнес-информатика»): автоматизация взаимодействия клиента и исполнителя через мессенджер-бота на примере типовой компании сферы бытового ремонта.


## Что внутри
| Папка | Содержание |
|---|---|
| `bpmn/` | Модели AS-IS (3 уровня) и TO-BE (3 уровня) в нотации BPMN |
| `analysis/` | Диаграмма Исикавы (причины неэффективности процесса), диаграмма Ганта (план разработки) |
| `uml/` | Варианты использования, классы, последовательность, компоненты, развёртывание |
| `prototypes/` | Прототипы экранов чат-бота |

## Логика работы
1. Анализ текущего процесса (AS-IS) и причин проблем (Исикава)
2. Целевой процесс (TO-BE) с ботом
3. Проектирование: роли, сущности, последовательность взаимодействий
4. Прототипы интерфейса и план разработки
